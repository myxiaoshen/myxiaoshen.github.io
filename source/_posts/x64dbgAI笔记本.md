## 一、⚠️ 常用 API 断点速查
---

### 🛠️ 1. 弹窗与提示类 (寻找破解爆破点)
**用途：** 当软件提示“注册失败”、“密码错误”时，拦截弹窗，向上回溯找判断逻辑。

| 断点函数名              | 用途描述                                                 |
| :---------------------- | :------------------------------------------------------- |
| `MessageBoxA` / `W`     | **最常用**。拦截标准的“确定/取消”提示框。                |
| `MessageBoxExA` / `W`   | 同上，带扩展功能的弹窗。                                 |
| `MessageBeep`           | 拦截系统提示音（有时候软件报错只响一声不弹窗）。         |
| `DialogBoxParamA` / `W` | 拦截自定义的对话框窗口（如关于界面、登录窗口）。         |
| `ShowWindow`            | 拦截窗口的显示或隐藏（常用于去启动广告、显示隐藏功能）。 |
| `CreateWindowExA` / `W` | 拦截窗口创建瞬间（用于分析程序启动流程、去广告窗）。     |

### 🔑 2. 输入框与字符串 (抓取注册码/密码)
**用途：** 当你点击“登录”或“注册”时，程序会读取你输入的内容。

| 断点函数名              | 用途描述                                           |
| :---------------------- | :------------------------------------------------- |
| `GetWindowTextA` / `W`  | **最常用**。获取一般窗口或输入框里的文字。         |
| `GetDlgItemTextA` / `W` | **常用**。专门获取对话框（Dialog）中输入框的文字。 |
| `GetDlgItemInt`         | 获取输入框里的**数字**（如输入数字验证码）。       |
| `lstrcmpA` / `W`        | **比较字符串**。真假注册码在这里“面对面”对比。     |
| `lstrcmpiA` / `W`       | 同上，但不区分大小写。                             |
| `strcmp` / `wcscmp`     | C语言标准库的字符串比较（不属于API，但很常用）。   |

### 📂 3. 文件操作 (补丁、Key文件、限制次数)
**用途：** 软件启动时读取 License 文件，或者把试用次数写在文件里。

| 断点函数名                 | 用途描述                                                   |
| :------------------------- | :--------------------------------------------------------- |
| `CreateFileA` / `W`        | **最常用**。打开或创建文件（不仅仅是创建，读取也要用它）。 |
| `ReadFile`                 | 读取文件内容（查看它读了 Key 文件的什么内容）。            |
| `WriteFile`                | 写入文件（拦截它写入“试用期已过”的标记）。                 |
| `GetPrivateProfileStringA` | 读取 `.ini` 配置文件里的设置。                             |
| `GetPrivateProfileIntA`    | 读取 `.ini` 配置文件里的数字。                             |

### ®️ 4. 注册表操作 (试用期、安装信息)
**用途：** 很多软件把注册信息或安装时间藏在注册表里。

| 断点函数名               | 用途描述                                              |
| :----------------------- | :---------------------------------------------------- |
| `RegOpenKeyExA` / `W`    | 打开注册表键（程序准备查户口了）。                    |
| `RegQueryValueExA` / `W` | **最常用**。读取注册表具体的键值（如 IsRegistered）。 |
| `RegCreateKeyExA` / `W`  | 创建/写入注册表键。                                   |
| `RegDeleteKeyA` / `W`    | 删除注册表键（重置试用期时可能用到）。                |

### ⏳ 5. 时间与定时器 (去广告倒计时、试用期过期)
**用途：** 启动时的 10 秒广告，或者软件提示“试用期已过”。

| 断点函数名                       | 用途描述                                             |
| :------------------------------- | :--------------------------------------------------- |
| `SetTimer`                       | **最常用**。设置定时器（倒计时广告、技能CD）。       |
| `KillTimer`                      | 结束定时器。                                         |
| `GetLocalTime` / `GetSystemTime` | 获取当前系统时间（判断是否过期）。                   |
| `GetTickCount`                   | 获取电脑开机运行了多久（常用于反调试，计算时间差）。 |

### 🌐 6. 网络验证 (抓包、改包)
**用途：** 必须联网才能登录的软件，拦截发送和接收的数据。

| 断点函数名               | 用途描述                                                   |
| :----------------------- | :--------------------------------------------------------- |
| `send`                   | **最常用**。发送数据包（拦截你输入的账号密码）。           |
| `recv`                   | **最常用**。接收数据包（拦截服务器返回的“登录成功”信号）。 |
| `WSASend` / `WSARecv`    | 异步网络收发（较新的软件常用）。                           |
| `connect`                | 拦截连接服务器的瞬间（获取服务器IP）。                     |
| `HttpOpenRequestA` / `W` | 拦截 HTTP 请求（浏览器控件或网页访问）。                   |
| `InternetOpenUrlA` / `W` | 打开一个 URL 链接。                                        |

### ⚙️ 7. 进程与线程 (注入、启动、反调试)
**用途：** 外挂、启动器、多开、反调试分析。

| 断点函数名             | 用途描述                                     |
| :--------------------- | :------------------------------------------- |
| `CreateProcessA` / `W` | 启动一个新的程序（如启动游戏子进程）。       |
| `CreateRemoteThread`   | **远程注入**（你刚才遇到的）。               |
| `OpenProcess`          | 打开一个进程获取权限（修改内存的第一步）。   |
| `ExitProcess`          | **自杀**。程序退出或闪退时调用。             |
| `TerminateProcess`     | 强行结束其他进程（杀反作弊，或反作弊杀你）。 |
| `IsDebuggerPresent`    | **反调试**。检查有没有调试器在挂着。         |
| `LoadLibraryA` / `W`   | 加载 DLL 模块（拦截插件、恶意 DLL）。        |

### 🖥️ 8. 界面控件控制 (灰色按钮、菜单)
**用途：** 把灰色的“不可用”按钮变亮。

| 断点函数名             | 用途描述                                            |
| :--------------------- | :-------------------------------------------------- |
| `EnableWindow`         | **最常用**。启用或禁用按钮/窗口（改 TRUE 就能点）。 |
| `IsWindowVisible`      | 判断窗口是否可见。                                  |
| `SetWindowTextA` / `W` | 设置窗口标题或内容（用于寻找哪里在修改界面）。      |

### 🐚 9. 执行与外壳 (打开网页、运行CMD)
**用途：** 拦截软件自动打开浏览器弹广告。

| 断点函数名            | 用途描述                                 |
| :-------------------- | :--------------------------------------- |
| `ShellExecuteA` / `W` | **最常用**。运行外部程序或打开网页链接。 |
| `WinExec`             | 运行外部程序（比较老，但还有人用）。     |
| `system`              | C语言运行系统命令（如 `del C:\`）。      |

### 💾 10. 硬件信息 (机器码绑定)
**用途：** 软件锁定电脑，换电脑不能用。

| 断点函数名                    | 用途描述                               |
| :---------------------------- | :------------------------------------- |
| `GetVolumeInformationA` / `W` | 获取硬盘序列号（最常见的机器码来源）。 |
| `GlobalMemoryStatus`          | 获取内存信息。                         |
| `GetNetworkParams`            | 获取网卡 MAC 地址。                    |

## 二、🛠️ x64dbg 实用技巧大全

| 技巧名称                                | 适用场景 (什么时候用？)                                      | 操作方法 (怎么用？)                                          | 核心原理 (人话解释)                                          |
| :-------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **硬件断点 (Hardware Breakpoint)**      | **最强神技**。当你知道某个数值（如血量、剩余天数）存在哪里，想知道**是谁改写了它**。 | 1. 在数据窗口找到那个数值的地址。<br>2. 右键 -> `断点` -> `硬件写入断点` (Word/Dword)。 | 在内存里放个“捕鼠夹”。谁敢动这个数据，程序立马暂停，**光标直接停在修改指令上**。 |
| **执行直到返回 (Execute till Return)**  | **迷路救星**。当你不小心 F7 进到了系统 DLL (如 kernel32) 里满屏乱码时。 | 按快捷键 **`Alt + F9`**。                                    | 让调试器自动跑完当前这个系统函数，**直接跳回**到你自己程序的代码领空。 |
| **修改标志位 (Toggle Flags)**           | **免修改测试**。遇到 `je/jnz` 跳转，不想改 NOP，只想**临时测试**一下“如果跳了会怎样”。 | 1. 选中跳转指令。<br>2. 看右侧寄存器窗口的 `ZF` (Zero Flag)。<br>3. **双击 `ZF`** (让 0 变 1，或 1 变 0)。 | 欺骗 CPU。本来该跳转的，你强制改了信号灯，它就不跳了。**适合测试逻辑，不用保存文件**。 |
| **搜索模块间调用 (Intermodular Calls)** | **全图透视**。不想运行程序，想直接看它**一共**调用了多少次 `MessageBox` 或 `CreateRemoteThread`。 | 1. 右键代码区 -> `搜索` -> `当前模块` -> `模块间调用`。<br>2. 在搜索栏输入函数名。 | 就像查看“通话记录”。不用等断点触发，直接把所有打电话给 API 的位置全列出来，**双击直接跳转**。 |
| **智能高亮 (Token Highlighting)**       | **眼力辅助**。代码太长，想知道寄存器 `EAX` 的值是从哪里传过来的。 | **鼠标左键单击** 代码里的 `EAX` (或任意寄存器/地址)。        | 所有用到 `EAX` 的地方都会变色。你可以像看连线图一样，一眼看出数据的来龙去脉。 |
| **修改 EIP (Set EIP)**                  | **时光倒流/瞬移**。手滑按快了错过了关键 Call，或者想跳过某段代码。 | 1. 选中你想去的那一行代码。<br>2. 右键 -> `在此处新建 EIP` (或者按 `Ctrl + *`)。 | 强行把 CPU 的指针抓起来，放到你指定的位置。**可以让程序倒回去重跑某一行，或者强行跳过一段坑**。 |
| **打补丁 (Patch)**                      | **保存战果**。修改了 NOP 想要保存，或者想撤销修改。          | 按快捷键 **`Ctrl + P`**。                                    | 管理你所有的修改记录。如果不想要了，可以在这里点“恢复”；如果确定了，点“修补文件”。 |
| **搜索字符串 (String References)**      | **入门必杀**。找提示语、文件名、网址。                       | 右键 -> `搜索` -> `当前模块` -> `字符串引用`。               | 全局搜索代码里出现的文字。找到 "Error" 或 "Success" 往往就找到了判断胜负的关键处。 |
| **NOP 填充**                            | **毁尸灭迹**。把不需要的代码（广告、注入、弹窗）删掉。       | 选中代码 -> 右键 -> `二进制` -> `使用 NOP 填充`。            | 用“空指令”覆盖原有指令，让 CPU 走到这里发呆，什么都不做。    |

## 三、⌨️ x64dbg 常用快捷键大全

#### 1. 🚶 核心“走路”键 (控制程序运行)
这是最常用的，控制程序怎么走、走多快。

| 快捷键       | 功能名称                          | 简单解释 (人话)                                              | 实战场景                                                     |
| :----------- | :-------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **F9**       | **运行 (Run)**                    | **全速前进**。直到遇到断点才停。                             | 程序刚加载好，或者想跳过无关代码直奔断点时用。               |
| **F8**       | **步过 (Step Over)**              | **走一步 (不进屋)**。遇到 `Call` 函数时，让它把活干完，直接去下一行。 | **最常用**。当你不想看函数内部细节，只想快速往下看流程时用。 |
| **F7**       | **步入 (Step Into)**              | **走一步 (进屋看)**。遇到 `Call` 函数时，**跳进函数里面**去一行行看。 | **慎用**。只有当你确定这个 `Call` 是关键函数(如验证算法)，想进去看它到底怎么算的时候才用。 |
| **F4**       | **运行到光标 (Run to Selection)** | **跑到这停下**。鼠标点哪，程序就跑到哪。                     | 想跳过一个巨大的循环，或者直接跳到下面某一行，不想下断点时用。 |
| **Alt + F9** | **执行直到返回**                  | **回城卷轴**。从系统领空或子函数里跳出来。                   | 不小心按 F7 进了 `kernel32.dll` 这种系统函数，赶紧按这个跳回主程序。 |

#### 2. 🛑 “打架”与修改键 (下钩子、改代码)
用来拦截程序和修改指令。

| 快捷键           | 功能名称            | 简单解释 (人话)                           | 实战场景                                                     |
| :--------------- | :------------------ | :---------------------------------------- | :----------------------------------------------------------- |
| **F2**           | **切换断点**        | **下钩子 / 取消钩子**。                   | 找到关键代码(如 `CreateRemoteThread`)，按一下变红，再按一下取消。 |
| **空格 (Space)** | **汇编 (Assemble)** | **改代码**。弹出窗口让你修改汇编指令。    | **最常用**。要把 `call` 改成 `nop`，或者把 `je` 改成 `jmp` 时用。 |
| **Ctrl + G**     | **跟随表达式**      | **传送门**。输入地址或API名，直接跳过去。 | 想直接去 `0x00401000` 或者想找 `MessageBoxA` 在哪时用。      |
| **; (分号)**     | **加注释**          | **做笔记**。在代码后面写中文备注。        | 这行代码是“判断密码”，那行是“注入”，防止过一会忘了。         |
| **:**            | **加标签**          | **起名字**。给这个地址起个好记的名字。    | 把 `0x004A20` 命名为 `Main_Injection_Function`。             |

#### 3. 🔙 “后悔药”与导航键 (迷路了怎么办)
调试的时候经常点错地方，这些键能救你。

| 快捷键           | 功能名称            | 简单解释 (人话)                        | 实战场景                                                     |
| :--------------- | :------------------ | :------------------------------------- | :----------------------------------------------------------- |
| **- (减号)**     | **后退 (Previous)** | **回到上一步**。像浏览器的“后退”按钮。 | 刚才看代码看飞了，按一下直接回到刚才看的地方。**非常实用！** |
| **+ (加号)**     | **前进 (Next)**     | **回到下一步**。像浏览器的“前进”按钮。 | 按减号按多了，再按加号回去。                                 |
| **Ctrl + F2**    | **重新启动**        | **重开一局**。重新加载程序，一切重置。 | 程序跑飞了、崩溃了、或者错过了断点，直接重来。               |
| **Enter (回车)** | **跟随**            | **进去看看**。                         | 选中一个跳转或 Call，按回车就会跳过去看那个地址的代码。      |

## 🖐️ 总结一套“丝滑连招”

1.  **F9** 跑到断点停下。
2.  **F8** 单步慢慢往下走，观察流程。
3.  遇到关键 Call 想要进去看，按 **F7**。
4.  发现进错地方了（全是乱码），按 **Alt+F9** 跳出来。
5.  看乱了，想回刚才的地方，按 **- (减号)**。
6.  搞砸了，按 **Ctrl+F2** 重开。
